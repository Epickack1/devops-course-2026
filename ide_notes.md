# Git в VS Code и в терминале
Удобно в VS Code:
1. Diff по клику на файл — видно, что именно изменилось, без git diff.
2. Добавление в индекс отдельных фрагментов (hunk) через кнопки в diff.
3. GitLens: автор и дата каждой строки прямо в редакторе.
Удобнее в терминале:
1. Интерактивный rebase (git rebase -i) — IDE его прячет или упрощает.
