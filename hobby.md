# Мой пет-проект
Идея: Telegram-бот, который напоминает о дедлайнах по учебным работам
и присылает сводку задач на день.
Стек: Python (aiogram), SQLite, Docker.
Цель: научиться собирать приложение в контейнер и разворачивать его
на сервере через CI/CD.

## Сроки реализации
1. Неделя 1–2: каркас бота на aiogram, команды /start и /add, хранение в SQLite.
2. Неделя 3: напоминания по расписанию и утренняя сводка задач.
3. Неделя 4: Dockerfile, сборка образа, запуск на сервере.
4. Неделя 5–6: CI/CD на GitHub Actions — тесты и автодеплой при push в main.

## Риски
- Лимиты Telegram Bot API на частоту запросов — нужна очередь отправки.
- Потеря данных при перезапуске контейнера — вынести SQLite в volume.
- Нехватка времени из-за учёбы — поэтому этапы маленькие и независимые.
